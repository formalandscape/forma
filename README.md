# FORMA · ландшафтна студія

Україномовний адаптивний сайт FORMA. Територія роботи — **виключно правий берег міста Києва**, у межах міста.

## Запуск у Codex

Відкрийте термінал у `/workspace/landscape-website` і виконайте:

```sh
npm start
```

Потрібен Node.js 20 або новіший. Встановлювати npm-пакети не потрібно. Сервер працює на порту 3000. Якщо інтерфейс Codex підтримує перегляд запущених застосунків або прокидання портів, відкрийте порт 3000. У режимі налаштування хмарного середовища перегляд може бути недоступний: у такому разі завантажте репозиторій і запустіть його локально. Адреса localhost у хмарі не є публічним посиланням на сайт.

## Запуск на Windows

1. Встановіть актуальну LTS-версію Node.js із https://nodejs.org (не нижче 20).
2. Завантажте репозиторій: **Code → Download ZIP**, розпакуйте архів.
3. Відкрийте папку проєкту в Провіднику. В адресному рядку введіть `cmd` і натисніть Enter.
4. Виконайте:

```bat
node --version
npm start
```

5. Відкрийте `http://localhost:3000` у браузері. Залиште термінал відкритим. Для зупинки натисніть Ctrl+C.

Якщо порт зайнятий, у командному рядку Windows:

```bat
set PORT=8080
npm start
```

У PowerShell використовуйте `$env:PORT=8080`, а якщо політика PowerShell блокує npm — команду `npm.cmd start`. Не потрібно послаблювати політику безпеки.

Не відкривайте `index.html` подвійним клацанням: модулі JavaScript потребують HTTP-сервера.

## Редагування

Основні дані — у **content.js**:

- `hero`, `about`, `process`: тексти, зображення першого екрана та етапи роботи.
- `services`: картки послуг. `visible: false` приховує картку й відповідні пункти форм. `confirmed: true` прибирає позначку непідтвердженої послуги — ставте лише після підтвердження.
- `projects`: галерея. Додайте фото до `assets/photos/`, задайте `image`, `full`, `alt`, `title`, `description`, `category`. `thumbnail` необов’язковий. `visible: false` приховує проєкт. `demonstration: false` використовуйте лише для підтверджених робіт FORMA з дозволом на публікацію.
- `categories`: категорії галереї. Значення `id` мають відповідати `category` у проєктів.
- `comparison`: замініть `before` та `after` парними фото **однієї ділянки з однакового ракурсу**, оновіть альтернативні описи й примітку. `visible: false` приховує блок. Зараз використано власну схематичну демонстрацію, не фотографії реального перетворення.
- `contacts.phone`: підтверджений український номер у форматі `+380XXXXXXXXX`. Натискання на номер у контактах копіює його; окрема кнопка швидкого дзвінка використовує `tel:`.
- `contacts.email`: контактна адреса на сайті й резервний mailto. Отримувача автоматичних заявок змінюйте в кабінеті Formspree; endpoint форми — `inquiryEndpoint`.
- `contacts.telegram`: посилання `https://t.me/...`; `contacts.viber`: підтверджене посилання Viber. `null` залишає явно позначені заглушки.

Для заміни hero-фото задайте `image` (1600 px) та `imageSmall` (900 px). Для цілковито нового тексту заголовок автоматично візьметься з `content.js`; декоративні переноси застосовано лише до початкового тексту.

Структура секцій, SEO-метадані й короткі підписи — у `index.html`; палітра й адаптивність — у `styles.css`. Тексти перевірки полів — у `app.js`.

## Заявки та розрахунок

Локальний сервер приймає лише GET/HEAD. Форма надсилає JSON без переходу зі сторінки на **https://formspree.io/f/mdeepwyp**. Endpoint зберігається в `inquiryEndpoint` файлу `content.js`. Адреса отримувача листів налаштовується **в кабінеті Formspree**, а `contacts.email` керує контактною адресою на сайті та резервним посиланням для звичайного листа. Для зміни отримувача оновіть обидва налаштування за потреби.

Під час надсилання кнопка та поля заблоковані. Лише успішна HTTP-відповідь із `ok: true` означає приймання заявки; це не доказ доставки у вхідні Gmail. При помилці, ліміті або таймауті дані залишаються у формі. Автоматичних повторів немає. Таймаут — 20 секунд. Приховане поле `_gotcha` та перевірки Formspree захищають від автоматичних звернень. Умови обробки даних: https://formspree.io/legal/privacy-policy/.

Реальний тест інтеграції повернув HTTP 200 та `{"next":"/thanks","ok":true}`. Власник має перевірити тестове звернення у Formspree та пошті, зокрема у папці «Спам». Пароль від Gmail у коді не використовується.

Телефон, ім’я та місцевість перевіряються до надсилання; порожні чи неправильні значення блокують POST. Калькулятор додає площу й стан ділянки у звернення; тарифів і фіктивних сум немає. Сайт не перевіряє географію адреси автоматично та не записує дані в localStorage чи cookie.

## Матеріали та публікація

Фотографії Unsplash — лише референси, а не портфоліо FORMA; джерела та умови наведено в `ASSETS.md`. Усі завантажувані сторінкою зображення локальні, оптимізовані у WebP. Системні шрифти не потребують зовнішніх запитів. Старі SVG-ілюстрації збережено як невикористовувані матеріали попередньої версії.

Сайт сумісний із GitHub Pages та звичайним статичним хостингом: потрібні `index.html`, `styles.css`, `app.js`, `content.js`, `inquiry.js`, `assets/`. Шляхи відносні й працюють у підпапці репозиторію. `server.mjs` потрібен лише для локального запуску.

Перед публікацією як повноцінного комерційного сайту власник має надати:

- підтверджені телефон, email, Telegram/Viber та, за потреби, години зв’язку;
- остаточний перелік послуг, їхній склад і доступність;
- реальні проєкти, описи, фото та дозволи на їх публікацію, окремо парні фото «До / Після»;
- узгоджені правила ціноутворення, якщо потрібен калькулятор із сумами;
- спосіб отримання заявок, відповідального за них і правила обробки даних;
- затверджені відомості про компанію, логотип та домен, якщо потрібен власний.

## Перевірки

```sh
npm run check
npm test
```

У браузері перевірте: меню телефона, фільтри, збільшення й перемикання фото, закриття через Escape, повзунок мишею/дотиком/стрілками, перенесення розрахунку, помилки форми, копіювання та режим зменшеного руху. Скрипт сервера сумісний із Windows та Node.js 20.0+; окремий запуск на Windows у хмарному Linux не перевіряється.

### Перевірка надсилання

`npm test` перевіряє протокол AJAX, помилки сервісу, таймаути та заборону помилкового успіху без зовнішніх запитів. Браузерні сценарії перевіряють валідацію, стан очікування, блокування повторної відправки, перенесення параметрів розрахунку та резервний варіант при помилці. Для остаточної перевірки потрібно перевірити налаштування отримувача у Formspree та реальне отримання тестового звернення в Gmail; перехоплені в тестах відповіді сервісу не є доказом доставки.
