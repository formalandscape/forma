# Зелена Форма

Адаптивний україномовний сайт ландшафтної студії: головна, філософія, послуги, портфоліо з фільтрами та діалогами, етапи роботи й контакти.

## Запуск

Потрібен Node.js 20 або новіший. Сторонніх npm-залежностей немає.

```sh
npm start
```

Сервер слухає порт 3000 на всіх інтерфейсах. Інший порт: `PORT=8080 npm start`.

```sh
npm run check
```

Альтернатива: розмістіть `index.html`, `styles.css`, `app.js` і `assets/` на статичному хостингу.

## Перед публікацією

- Назва студії та портфоліо — демонстраційні. Замініть концепції реальними роботами й перевіреними фотографіями.
- Додайте справжні контакти компанії. Форма зараз лише формує текст для копіювання: дані не відправляються й не зберігаються. Для отримання заявок потрібен окремий поштовий або серверний сервіс.
- Усі ілюстрації та логотип зберігаються локально в `assets/`. Використовуються системні шрифти. Сайт не потребує зовнішніх ресурсів.

## Структура

- `index.html` — семантична розмітка українською.
- `styles.css` — стилі для комп’ютерів і телефонів, підтримка reduced motion.
- `app.js` — меню, фільтри, діалоги та підготовка звернення.
- `server.mjs` — сервер статичних ресурсів без зовнішніх залежностей.
- `assets/leaf.svg` — локальний логотип і favicon.
