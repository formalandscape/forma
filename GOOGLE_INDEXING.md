# Індексація FORMA в Google

Основна адреса: https://formalandscape.github.io/forma/
Карта сайту: https://formalandscape.github.io/forma/sitemap.xml

## Що налаштовано

У HTML є заголовок і опис сторінки, українська мова, canonical на основну адресу, og:url та посилання на sitemap.xml. Карта містить одну сторінку: секції з #about, #services тощо не є окремими сторінками. Параметри версій ?v=… не додаються до sitemap.

Після перейменування акаунта й репозиторію актуальний проєкт — formalandscape/forma. Нова адреса https://formalandscape.github.io/forma/ повертає HTTP 200. Robots.txt діє лише в корені хоста, тому файл у /forma/ не створюється.

## Дії власника в Google Search Console

1. Відкрийте https://search.google.com/search-console і натисніть «Додати ресурс».
2. Оберіть «Префікс URL» та введіть точно https://formalandscape.github.io/forma/ з HTTPS і кінцевою рискою. DNS-підтвердження всього github.io для цього не потрібне.
3. Для способу «HTML-файл» уже додано наданий власником файл googlec1003d020b97f89b.html без зміни вмісту. Публічна адреса: https://formalandscape.github.io/forma/googlec1003d020b97f89b.html . Суфікс « (1)» із назви завантаження прибрано: Google очікує оригінальну назву. Файл потрібно зберігати й після підтвердження.
4. Коли файл опубліковано, поверніться до способу «HTML-файл» у Search Console і натисніть «Підтвердити».
5. У розділі «Файли Sitemap» подайте sitemap.xml (повна адреса наведена вище).
6. Через «Перевірка URL» перевірте основну адресу та натисніть «Запросити індексування». За потреби перед запитом запустіть перевірку опублікованої сторінки.

Саме натискання «Підтвердити», подання sitemap і запит індексації ще не виконані: акаунт Search Console до середовища розробки не підключений. Файл підтвердження надано власником і додано до проєкту. Публікація sitemap сама собою не означає, що запит уже подано в Google. Google самостійно вирішує, коли сканувати й індексувати сторінку; наявність у пошуку й позиція за запитами не гарантуються. Статус перевіряйте в Search Console.

При переході на власний домен оновіть canonical, og:url і sitemap та додайте новий ресурс у Search Console.

Адреса forma.github.io належить простору імен організації GitHub forma. Підключений акаунт після перейменування — formalandscape. Для перенесення туди потрібні відповідні права в організації; назва репозиторію цього проєкту сама по собі не змінить власника github.io. Власник підтвердив, що доступу до організації forma немає. Тому фактична адреса після перейменування акаунта та репозиторію — https://formalandscape.github.io/forma/; саме її внесено до canonical та sitemap. У Search Console потрібен ресурс із цим префіксом URL, а не forma.github.io чи попередньою адресою /landscape-website/.
